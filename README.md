# manas-live-traker


## Installation
1. **Clone the repository**:
```bash
git clone https://github.com/madhanmaaz/live-location-tracker.git
cd live-location-tracker
```

2. **Install dependencies**:
```bash
npm install
```

3. **Run the application:**
```bash
npm start
```

4. Login credentials
```js
username: manas.in
password: manas.in
```
